# Proof-Of-Concept

To run this solution

1. Run `yarn install` in the folder with the `package.json` file
2. Next `yarn dev`, verify the port the service binded to
3. Open your browser and navigate to the local web app

## Network

This is hardcoded to work on the `chipnet` BitcoinCash network

## Disclaimers

This implementation is not completely trustless and should not be used beyond a proof-of-concept purpose.

This proof-of-concept has not been audited.
